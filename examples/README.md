# Примеры

`example_prediction.json` показывает контракт результата на проверочном изображении: мужчина улыбается в скейтпарке.

Собственные изображения можно проверить командой:

```bash
python svoa.py infer \
  --model ./florence2_svoa_model/best_model \
  --image /path/to/image.jpg
```

Изображения и веса намеренно не включены в репозиторий. Это сохраняет небольшой размер проекта и не смешивает код с артефактами обучения.
