# Подготовка датасета

## Источники

Pipeline умеет получать выборки из SWiG, GQA, Open Images, Mutual Gaze, EasyPortrait, WIDER FACE и HaGRID. Источники дополняют друг друга: события, сцены, лица, взаимный взгляд и жесты.

Репозиторий не распространяет полный набор изображений. Перед публикацией производного датасета необходимо отдельно проверить лицензии и условия каждого источника.

## Этапы

```text
изображения
→ нормализация до 768×768
→ первичная SVOA-разметка VLM
→ коррекция SWiG официальными аннотациями
→ коррекция HaGRID официальными классами жестов
→ dataset.jsonl
```

Команда верхнего уровня выполняет эти операции автоматически:

```bash
python svoa.py prepare --env-file .env --limit-per-dataset 5000
```

## SWiG

Официальная разметка применяется только при однозначном сопоставлении изображения, роли и согласованного noun label. Невидимые, не имеющие grounding участники по умолчанию не заменяют визуальную метку VLM.

## HaGRID

Официальный класс меняет только поле `action`. Подчёркивания преобразуются в пробелы без смысловой интерпретации:

```text
little_finger → little finger
thumb_index2 → thumb index2
three_gun → three gun
```

`no_gesture` полностью сохраняет исходную разметку VLM. При нескольких руках учитываются `united_label`, одинаковые классы и площадь bounding box. Полные исходные метки сохраняются в метаданных.

## Разбиение

Чтобы исключить утечку, связанные кадры одного видео или эпизода должны попадать только в один split. Случайное разделение соседних кадров способно существенно завысить результат.

## Артефакты

- `dataset_vlm.jsonl` — исходная разметка VLM;
- `dataset_swig_corrected.jsonl` — промежуточный результат SWiG;
- `dataset.jsonl` — окончательный обучающий набор;
- `*_corrections.jsonl` — аудит изменений;
- `*_correction_summary.json` — сводная статистика.
