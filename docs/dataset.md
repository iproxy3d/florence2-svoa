# Подготовка датасета

## Источники

Pipeline умеет получать выборки из SWiG, GQA, Open Images, Mutual Gaze, EasyPortrait, WIDER FACE и HaGRID. Источники дополняют друг друга: события, сцены, лица, взаимный взгляд и жесты.

Репозиторий не распространяет полный набор изображений. Перед публикацией производного датасета необходимо отдельно проверить лицензии и условия каждого источника.

## Загрузка больших выборок и возобновление

Установите зависимости для скачивания и выполните:


```bash
python -m pip install -e ".[download]"
python svoa.py download --limit-per-dataset 50000
```

Повторный запуск с тем же каталогом сохраняет прогресс: успешные изображения
учитываются в downloaded_images_v2/download_state.sqlite3 и не скачиваются
повторно. Файл downloaded_images_v2/manifest.jsonl формируется из существующих
файлов. Загрузка может завершиться частично: целевой лимит не гарантирует, что
исходный split содержит столько изображений или что сервер доступен.

SWiG, EasyPortrait, WIDER FACE и HaGRID читаются из удалённых ZIP при помощи
HTTP Range. По умолчанию файлы упорядочены по физическому смещению внутри ZIP,
а перемешиваются только непрерывные блоки по 256 файлов. Это уменьшает число
дальних переходов по сравнению с перемешиванием каждого файла и сохраняет
возможность выборки из разных частей архива. Для нестабильного сервера можно
полностью отключить перемешивание:


```bash
python svoa.py download --limit-per-dataset 50000 \
  --archive-shuffle-block-size 0 \
  --archive-member-retries 4
```

Дополнительные параметры: --request-timeout (также применяется к RemoteZip),
--max-errors (всего неудачных изображений в одном источнике или классе;
по умолчанию 1000), --max-consecutive-errors (подряд, по умолчанию 15),
--archive-member-retries (дополнительные попытки, по умолчанию 3) и
--archive-shuffle-block-size (0 — строго последовательный порядок).

Для HaGRID загрузчик обрабатывает классы независимо и продолжает со
следующего класса даже после ошибки текущего. Верхнеуровневая команда
распределяет лимит примерно поровну между 34 официальными классами: при
50000 это по 1470 изображений на класс (всего 49980). Для GQA, Open Images
и Mutual Gaze повторный запуск заново просматривает ранее пропущенные
позиции при наличии записей status=failed в SQLite; старый указатель
следующей страницы не теряется.

Для диагностики смотрите downloaded_images_v2/source_status.json и
таблицу downloads в downloaded_images_v2/download_state.sqlite3.
Статусы available/cached обозначают достигнутую цель, partial — неполный
набор, failed — отсутствие скачанных изображений. Вы можете передать
--strict для ненулевого exit code при незавершённых источниках.
Ни один режим не скачивает большие ZIP целиком автоматически.

## Этапы

```text
изображения
→ нормализация до 768×768
→ первичная SVOA-разметка VLM
→ коррекция SWiG официальными аннотациями
→ коррекция HaGRID официальными классами жестов
→ dataset.jsonl
```

Команда верхнего уровня выполняет эти операции автоматически:

```bash
python svoa.py prepare --env-file .env --limit-per-dataset 5000
```

## SWiG

Официальная разметка применяется только при однозначном сопоставлении изображения, роли и согласованного noun label. Невидимые, не имеющие grounding участники по умолчанию не заменяют визуальную метку VLM.

## HaGRID

Официальный класс меняет только поле `action`. Подчёркивания преобразуются в пробелы без смысловой интерпретации:

```text
little_finger → little finger
thumb_index2 → thumb index2
three_gun → three gun
```

`no_gesture` полностью сохраняет исходную разметку VLM. При нескольких руках учитываются `united_label`, одинаковые классы и площадь bounding box. Полные исходные метки сохраняются в метаданных.

## Разбиение

Чтобы исключить утечку, связанные кадры одного видео или эпизода должны попадать только в один split. Случайное разделение соседних кадров способно существенно завысить результат.

## Артефакты

- `dataset_vlm.jsonl` — исходная разметка VLM;
- `dataset_swig_corrected.jsonl` — промежуточный результат SWiG;
- `dataset.jsonl` — окончательный обучающий набор;
- `*_corrections.jsonl` — аудит изменений;
- `*_correction_summary.json` — сводная статистика.
