# Формат SVOA

Модель возвращает одну строку из четырёх полей:

```text
subject|action|object|adjuncts
```

## Поля

### `subject`

Главный видимый участник события или связная группа. Значение состоит из одного английского слова: `man`, `woman`, `dog`, `people`. `none` используется, только если участника определить нельзя.

### `action`

Непосредственно наблюдаемое действие в базовой форме: `smile`, `run`, `hold`, `look`. Для официальных жестов HaGRID допускаются многословные канонические названия: `little finger`, `thumb index2`, `three gun`.

Название жеста фиксирует наблюдаемую конфигурацию и не интерпретирует её культурное или эмоциональное значение.

### `object`

Видимая цель или объект именно указанного действия. Место, фон и случайный соседний предмет сюда не включаются. Если прямого объекта нет, используется `none`.

### `adjuncts`

Одно полезное видимое обстоятельство: место, спутник, атрибут, время или способ действия. Поле состоит из одного слова.

## Специальные значения

- `none` — роль отсутствует или действие не имеет объекта;
- `unknown` — роль визуально существует, но надёжно определить её нельзя.

## Проверка

Пакет строго проверяет количество полей, допустимые символы и отсутствие лишних ключей. Некорректный ответ не дополняется придуманными значениями:

```python
from florence2_svoa import parse_generation

result = parse_generation("person|smile|none|park")
assert result.valid
assert result.event.action == "smile"
```
